# @victorhg/pi-hallmark

A Pi extension designed to prevent AI-generated websites from looking like generic "AI slop." This extension helps maintain high design standards by enforcing anti-cliché principles during the development process.

## Features

- **Design Audit**: Analyzes your frontend code for common AI design markers (e.g., generic gradients, standard card layouts, over-rounded corners).
- **Anti-Slop Gates**: Provides structural guidance to move away from "default" aesthetic choices often generated by LLMs.
- **Commands**: Integrates directly into your Pi CLI.

## Installation

```bash
# Within the monorepo
pnpm install
```

## Commands

| Command | Description |
|---|---|
| `hallmark audit <file-path>` | Flags common AI design "tells" in the specified code. |
| `hallmark generate <brief>` | Generates a landing page structure using anti-slop principles. |

## Motivation

This project is a Pi-native adaptation of the original [Hallmark](https://github.com/Nutlope/hallmark) concept, specifically tuned for the Pi agent architecture to provide real-time design feedback during the coding loop.
